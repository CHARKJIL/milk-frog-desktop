# 奶蛙动画素材

双击 `preview.html` 可在本地预览九组动作及鼠标视线跟随。

- `spritesheet.png`：v2，1536×2288，73 帧透明 PNG。
- `spritesheet-v1-legacy.png`：兼容旧版界面的前九行，1536×1872。
- `all-actions.gif`、`all-actions.mp4`：基础动作预览。
- `idle-jump-idle.gif`：待机、小跳、回到待机。
- `look-around.gif`：十六个观察方向。
- `states`：每组独立动画。

导入到应用内宠物时，按实际界面支持的格式选择动作图。官方说明：https://learn.chatgpt.com/docs/pets。

接近正上方的 337.5° 姿势，向左的分量较轻；上、下、左、右四个主方向经过独立复核。
